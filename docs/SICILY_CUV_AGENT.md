
# 西西里 CUV 助手

在燃气中控右上角选择「西西里」，点击「智能助手」。助手基于作者公开的高压输气研究样本工作。它分别显示作者发布的分时稳态、本站图连通推演和已有的独立稳态复核。

## 演示

1. 问「当前有哪些数据」，可核对 340 个节点、350 条管段、456 个分时输入和 436 个小时的完整发布结果。
2. 问「254 号管段连接哪两个节点」，通过证据表打开拓扑，再追问「它的流量」。
3. 问「按新增断连节点数优先，比较 342 和 254 号管段退出」。核对工况和管段后点一次「确认运行」。同工况的已有结果可以直接复用。
4. 点击「回放管段 254 结果」，再问「为什么这次有节点断连」。回答附执行编号、输入 SHA-256、断连对象及图连通依据。

## CUV 工程实现

- **C 认知与选择**负责工具选择、对象指代、工况和会话绑定。Qwen 返回受约束意图，服务端验证后使用。
- **U 能力**复用版本锁定的西西里数据、工况与拓扑服务。三个阶段复用一次已执行的拓扑结果。已计算输出按执行 ID 保存和读取。
- **V 约束与取舍**校验数据授权、确认有效性、输入指纹及两案可比性。确认卡限同一工况下至多两个场景，有效期五分钟。SQLite 串行登记确认和执行结果，重复确认返回同一结果。比较仅使用新增断连节点数与断连模型需求，不据此生成现场处置或优劣总分。

SQLite 默认写到 `engineering/outputs/research/sicily-agent.sqlite`，可用 `GAS_SICILY_AGENT_STORE` 设置路径。记录按主体和高熵会话标识隔离。刷新页面会开启新会话；同一页面关闭再打开面板会保留对话。

## Qwen 与本机运行

可复用项目既有本机 Qwen 网关配置。需要使用之前授权的院内 Qwen3.8-27B 兼容接口时，在启动后端的 PowerShell 设定 `GAS_SICILY_QWEN_MODE=institute`，将 `GAS_SICILY_APPROVED_QWEN_ORIGIN` 设为管理员批准的模型服务 origin，将 `OPENAI_BASE_URL` 设为该 origin 加 `/v1`。密钥从该进程的 `Qwen3.8` 或 `OPENAI_API_KEY` 读取。接口地址与模型固定校验。浏览器只访问本机后端。

使用 `scripts/start-gas-public.ps1` 启动同一组前后端端口。内网连接超时或模型返回不符合合同，回答保留规则查询状态。Qwen 的模型调用、规则降级和专业求解验证分别记录。

`web/scripts/sicily-agent.browser.mjs` 可在 Windows Chrome 验收确认卡、两案比较、回放和结果解释。截图和浏览器记录写到 `engineering/outputs/research/browser/sicily-agent/`。
