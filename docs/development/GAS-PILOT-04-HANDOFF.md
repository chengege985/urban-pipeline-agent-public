# 燃气首批试点数据交付与验收

本包提供空白字段模板。清单里的示例仅说明合成数据格式。首批资料由运营方审批后，经双方确认的受控途径移交。

| 文件 | 填写责任与用途 |
| --- | --- |
| `A-首批必需/` | 台账负责人与监测负责人填写节点、管段、测点、历史观测。最终导出格式在清单中逐列映射 |
| `字段口径与填报清单.csv` | 查字段类型、单位、来源、关联键和缺失影响。优先交齐 A 类，按获准用途补齐 B 类 |
| `数据授权与使用范围确认表.csv` | 权属方确认主体、用途、区域、资产、时间范围、最终清单摘要和撤销方式。签批凭证由双方各自按制度保管 |
| `B-运营方签批与核验/threshold_rules.csv` | 运营方按测点、版本与上下限逐条签批，填写生效和截止时间、批准人、批准时间和证据号 |
| `B-运营方签批与核验/events.csv`、`truth_windows.csv`、`truth_events.csv` | 事件负责人提供事件、观测和资产关联。核验人填写审核覆盖、事件真值、确认恢复时间及出处 |
| `字段统计.json` | PILOT-02 历史口径与本包统计。以表名及字段名组成唯一键，同名外键和版本字段可跨表复用 |

## 填表和版本

- A 类可完成准入、历史读数回放、资产关联与来源追溯。GIS、事件、签批阈值、质量理由和人工真值属于 B 类。没有批准阈值时显示原始读数，缺少完整人工真值时只进行规则一致性检查。
- 每行保留源系统记录 ID。绑定节点、管段、测点和观测时，沿用同一批次的实际关联。时间使用带时区 ISO 8601，缺测留空并填 `missing`，保留原始压力和流量单位。阈值审批和真值核验使用独立证据编号。
- 阈值条款仅在 `approved` 且观测位于生效区间时用于规则回放。一个测点同一时点只能有一个生效版本。历史人工核验窗口若完整且无事件，保留 `truth_events.csv` 表头，并提交窗口审核凭据。
- C 类 9 项供后续工程模型校核单独确认，当前导入只解析 A 与 B 中的数据合同。GIS 条件和观测质量口径以运营方批准的来源为准。

## 脱敏、保存与撤销

- 按批准范围导出最小资产集及历史时段。删除非业务所需的个人、调度说明等列。需要代号化时，跨表使用同一稳定代号，映射表留在运营方授权环境。原始坐标按 GIS 许可单独交付。来源记录号及经授权的适用范围继续可查。
- 传输前核对文件摘要。交付目录、授权登记、SQLite 和原件放在获准的 Git 外位置，使用受控系统账户。试点库目录权限 0700，库和私有登记文件 0600。真实业务原件与日志不随源码、公共站点或合成发行包同步。
- 批准方撤销或到期时，由维护人更新独立授权登记并核查读取拒绝。可隔离受影响的版本并保留操作回执。保管、清退与留存证据依双方签批约定执行。需再次入库时复核最终清单、范围和操作者。

## 导入和验收顺序

1. 将获准表存放在同一个受控来源目录。对新增 B 类表，使用现有导入器的 `template --profile full` 生成标准映射，按实际提交表登记进 `manifest.json`。填写源系统、版本和最终文件 SHA-256。
2. 真实交付采用获准的 `dataset_id` 与 `real_authorized`。平台维护人将签批结果登记在私有 `approvals.json`，按最终清单字节算摘要，绑定交付路径、主体、区域、资产、历史时段和用途。确认表作为审批凭据保存。
3. 在受控环境运行现有 CLI 的 `preview` 和 `ingest`。命令如下，实际目录和账号以签批为准。修正有误来件时登记新版本和新摘要。

```bash
cd /nix/wpn-mainline-unify-20261118/engineering
export PYTHONPATH=.
python -B -m src.gas_application.pilot_cli preview /approved/inbox --store /approved/private-pilot
python -B -m src.gas_application.pilot_cli ingest /approved/inbox --store /approved/private-pilot --actor approved-operator
```

4. 从试点目录核验版本、状态、覆盖、拒收和缺项。通过授权读者回放观测，核对管段、事件、阈值和原始行的证据，并验证其他主体无法读取。需展示 GIS、调用本机 Qwen 或作人工真值对照时分别核对用途。正式工程 CUV 校核、实际供气及现场处置单独验收。

Release 04 一键包用于合成演示。运营方正式试点启用前，需确认签批、真实历史观测、阈值、人工真值和账号管理。
