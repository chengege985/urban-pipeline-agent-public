# 燃气合成监测预警

在项目版燃气中控的「事件与情景」打开「合成监测预警」。可查看压力、流量和各自的预警历史，从记录打开 GAS-M0 关联管段，并回查来源和原始数据行。

## 回放规则

- 回放使用版本化合成包和燃气数据只读适配。窗口固定为 2026-11-18 01:00–01:12 UTC，每分钟一个采样槽。合成演示策略为 syn-gas-monitoring-policy-0.1.0。
- 同方向连续 3 个有效采样槽越过演示上下限才确认持续越限。连续 2 槽没有可用观测确认数据缺失。正常区间包含上下限端点。持续越限的方向反转也需要重新确认。坏值、疑似值和无值不补零。
- 有效正常读数可确认恢复。缺失后首个有效读数仍越限时，记录数据恢复，越限仍要满足连续性。回放截止未恢复的状态继续显示。
- K-001 压力的演示范围为 4–6 kPa。回放中 01:03 确认高限、01:04 恢复、01:07 确认缺失、01:08 恢复、01:12 再次确认高限。K-003 流量的演示范围为 12–30 Nm3/h。回放中 01:04 确认缺失、01:05 恢复、01:09 确认低限、01:10 恢复、01:12 再次确认缺失。

## 只读接口与来源

GET /api/v1/gas/engineering/monitoring 复用 GAS-M0 的合成数据集访问控制。服务端管理数据路径、时钟和演示策略。接口返回回放版本、清单 SHA-256、策略和确认时点、资产台账行、监测来源版本及 SHA-256、观测原始行与采样时间。缺失证据列出预期采样时点，并可引用缺失前最后一条有效观测。有被质量规则排除的观测时可引用其来源。回放包或关联资产不可用时返回 503。

CUV 可按资产、测点、指标和时点引用回放输入，并同时保留策略版本、数据模式和证据。当前状态标记为 synthetic 和 not_business_validated。正式阈值、采样时钟、质量规则、授权测点映射、物理模型验证与监测上线需按正式数据授权及业务验收落实。
