# 燃气 CUV 人机协同演示

项目版燃气中控的「应急推演 → 比较隔离与恢复方案」可让 Qwen 解释当前推演，并在操作身份下对比较口径进行人工复核。演示数据、时点和约束采用 GAS-M0 合成场景。

## 只读查询

从推演面板发起 Qwen 查询时携带当前事件、资产和对应的合成时点。服务端核对资产关联和时点，根据当时的图状态与全窗口方案统计提供证据。可以查看案例和拓扑摘要、监测的最新可用来源、观测行和缺测时点。后续观测保持在原时间范围内。Qwen 只选择已有证据解释，模型不可用时由规则返回同一只读推演。

只读结果报告 GAS-M0 案例、合成监测或 CUV 图计算的来源版本和摘要。比较追问沿用上次结果的推演配置摘要、输入摘要和修订号。当前修订变化时返回 409，需从最新人工确认卡重新查询。试点历史回放使用自己的数据集、清单和生效阈值，跨范围请求提示关联未经核验。操作说明、反馈与历史审计只保留在人工协同入口。

[燃气 CUV 工程校核准备](GAS-CUV-ENGINEERING.md)列出正式物理计算的输入、校核顺序和指标启用条件。

## 人工确认与记录

- 比较目标可在最小累计图影响与最早恢复到基线服务图可达之间切换。可设置新增图不可达服务的峰值上限和服务图可达恢复时限。人工预览、确认后重新筛选和排名，保留并列、超限和证据不足的情况。
- 确认请求绑定完整推演输入摘要与当前修订号。过期的摘要或修订会返回 409，刷新后重新复核。审计逐次保存主体、时间、推演摘要、前后比较口径、反馈和结果。
- 隔离的本机演示预览把审计保存到私有运行目录的 SQLite。同一运行目录重启后可用重新发放的操作登录查看已有记录。直接启动 API 且仅配置内存模式时，记录随进程重置。演示操作身份代表该本机角色。正式主体管理与持久化环境需要另行验收。

实际供气、压力、流量、现场复气、失效概率和成本在推演中保留未知。人工确认只记录合成案例的比较口径和结果。

## 启动当前源码

完成项目版构建后，在私有 129 运行目录启动合成协同演示。设置 WPN_GAS_CUV_COLLABORATION_DEMO=1 后使用 scripts/start_gas_demo.sh，运行 bash scripts/gas_demo.sh operator-credentials 在交互终端取得操作登录。普通登录仍提供已授权只读查询。
