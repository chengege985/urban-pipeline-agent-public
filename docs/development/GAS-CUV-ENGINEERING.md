# 燃气 CUV 工程校核准备

当前可执行的[工程输入合同与校核清单](GAS-CUV-ENGINEERING-INPUT.md)含能力门禁与运营方字段映射。

## 已验证的范围

GAS-M0 在同一合成拓扑和故障假设上比较分阶段恢复与维持隔离。当前图计算按禁用管段、关阀切点和禁用来源检查可达性，并验证假设故障清除前的图隔离约束。输出包括新增图不可达服务数、峰值、累计服务对象·小时及回到基线图可达状态的合成时点。阶段时点取自算例输入。监测、案例事件和拓扑通过已登记的合成资产与回放时点关联，观测值用于解释上下文。详见[合成方案对比](GAS-CUV-REPLAY.md)。

试点历史回放按授权数据集、版本、清单摘要、观测、回放窗口及生效阈值读取证据。GAS-M0 图 CUV 绑定案例和网络内容摘要、推演配置摘要及比较输入摘要。人工比较还绑定当前操作主体和修订号。当前没有签核的跨数据集映射，同名管段或相近时间不足以建立关联。

| 管网设备 | 阀门、调压器和适用的增压设备 ID、连接方向、核验时点状态、设置值、允许运行范围及经批准的设备特性 | 设备台账和运营记录，保留特性文件版本、压力口径及测量单位。设备状态不明时隔离或恢复可行性保持未知 |
| 供需边界 | 边界节点和有效时段、入口压力或流量约束、出口负荷与最低服务压力、设备边界及切换记录 | 调度及获准监测记录。压力登记表压或绝压及测点高程。体积流量登记工况、标准状态和换算口径。缺少有效边界时相应工况不进入校核 |

| 校核证据 | 管段、测点、原始观测和人工核验事件的稳定关联。观测时间、采样间隔、单位、质量码、校准记录与授权范围 | 通过现有试点准入机制校验。有签批阈值和审核覆盖才评价历史告警。缺少独立事件标注时不报告业务准确率 |

台账、观测及正式阈值沿用[首批试点交接包](GAS-PILOT-04-HANDOFF.md)。设备特性、供需边界及模型参数由运营方和专业模型负责人另行确认。每批绑定数据版本、内容摘要、来源、主体、区域、资产、历史时段及用途。授权交付物和计算证据存放于获准的 Git 外环境。GasLib 的网络元素合同和边界数据可用于软件基准测试。项目模型和业务校核需使用本试点适用的专业方法和独立证据。[GasLib 技术文档](https://gaslib.zib.de/documentation.html)

## 模型校核与比较

1. 登记模型名称、求解方式和版本、计算配置与容差、输入快照、单位转换版本及时间对齐规则。由专业负责人确认稳态或瞬态范围、设备边界和缺项处理。
2. 先用公开基准及合成输入核对拓扑映射、单位转换、初始与边界条件、求解收敛和质量守恒。对缺项、互相冲突的边界及不收敛工况保留结构化原因和未知结果。
3. 授权历史资料齐备后，由专业负责人划分校准与独立校核时段，核对测点压力和流量的偏差、时序响应及不确定性，登记有效工况范围和可复现的计算输入、诊断与报告。容差与指标启用条件由运营方和专业团队签认。
4. 图方案继续比较图影响、峰值、基线图可达恢复时点及约束满足情况。工程方案在校核通过后方可比较有效工况内的服务压力、供需缺口、影响范围及不确定性。现场恢复时间还需另行验证工程工序与许可条件。缺证据的指标保持未知。

## 人工确认

Qwen 从只读工具选择结构化证据。人工操作主体在合成演示中确认目标与约束后重算，审计绑定主体、时间、输入摘要、修订号、前后口径、结果及反馈。版本冲突须重新读证据。真实工程方案需要授权主体、签核记录和独立业务验收。演示确认只写本地隔离的审计记录。
