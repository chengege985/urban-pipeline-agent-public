# 燃气 CUV 工程输入合同与校核清单

合同版本 `gas-cuv-engineering-input/1`。本合同登记模型准入所需的输入、来源及缺项。GAS-M0 的运行合同由 `cuv_engineering.py` 提供。运营方现有字段逐项映射见[109 项字段与工程用途](../templates/gas-cuv-engineering-field-map.csv)。交付格式及授权沿用[试点交接包](GAS-PILOT-04-HANDOFF.md)。

## 现有计算

`network.evaluate_case` 按无向拓扑和给定状态计算气源可达范围。`cuv_replay.compare_cuv_replay` 校验故障、隔离、方案时序和故障端点图通路，汇总服务对象的图可达影响。基线的合成分阶段方案和维持隔离方案累计图影响分别为 35 和 37 服务对象·小时。阶段时长取自固定算例。人工比较仍按输入摘要及操作主体的修订处理。详见[既有合成算例](GAS-CUV-REPLAY.md)。

## 主键、来源和缺项

| 输入组 | 必须关联及核验的记录 | 缺项影响 |
| --- | --- | --- |
| 数据与授权 | 数据集 ID、版本、清单摘要、来源记录号、授权主体、资产、地域、用途、历史时段及有效期。业务原件和校核凭据由获准环境保管 | 不能将数据用于对应工程场景 |
| 节点、管段和连线 | 节点与管段各自有稳定 ID。管段两端、阀门及调压设施的连接点解析到同一有效版本；明确气源边界节点和负荷节点。GIS 几何以管段 ID 和授权范围关联，保留坐标系 | 无明确连通关系的范围无法比较图影响或物理运行结果 |
| 管段物理 | 以管段 ID 提供确认过口径的内径、测绘长度、材质、粗糙度依据、压力等级和高程。长度与高程注明单位和基准，保留原值、换算版本及量测日期 | 稳态及瞬态压力流量校核受阻。现有 `diameter_mm` 需确认内径口径 |
| 阀门与调压设施 | 设备 ID、设备类型、上游及下游连接、方向、实际状态、有效时点、设置值、运行限值及经批准特性。以同一网络版本关联；阀门切点用于给定合成图状态 | 缺少真实设备特性或状态时，正式隔离及恢复可行性保持未知 |
| 气源与负荷 | 上下游边界节点、边界类型、获准的压力或流量条件、供需曲线、服务对象口径、运行时段。明确压力表压或绝压、体积流量参考状态、流量方向及单位 | 稳态压力流量和供气评价受阻 |
| 气质与初始状态 | 介质、温度和参考状态的来源版本与适用时段。瞬态校核另需与场景时钟一致的初始状态、边界时序、设备变化和工程条件 | 介质或边界不全时无正式物理解。无独立初始状态时无瞬态恢复评价 |
| 监测与质量 | 观测 ID、测点 ID、对应资产或节点、带时区时点、指标、原始值、单位、质量码、校准和状态。按校核窗口核对覆盖、重复、单位与时序，缺测显式标注 | 缺少独立可用观测则无法验证模型偏差。历史规则预警仍按获准阈值回放 |
| 业务验证与模型 | 方法与版本、适用网络和工况、配置和单位转换、参考结果、签核容差、验证报告及批准主体。现场恢复另需独立事件时序、业务判据和核验记录 | 没有批准的专业依据时，供气率、正式压力流量和现场恢复时长保持未知 |

## 校核顺序

1. **数据准入**　由运营方核对授权用途、版本和来源证据。检查主外键、设备连接、有效期、单位、时区和质量覆盖。由专业模型负责人确认缺项影响和能否使用该工况。
2. **程序基准**　用已登记的合成算例检查图约束及阶段统计。未来物理模型应独立登记求解版本、基准输入与参考输出、收敛和守恒检查、诊断及容差依据。
3. **独立专业校核**　匹配授权快照、时点、观测和设备边界。将参数校准与独立核验分开，记录各工况的偏差、适用条件和有效期。服务达标与现场恢复指标须有运营方单独签核。
4. **结果与审计**　结果关联输入摘要、模型版本、方案配置及当前比较修订。记录人工确认主体、时点和反馈。Qwen 按只读工具证据解释，人工确认沿用现有合成审计入口。

## 当前门禁

[Weymouth 单管稳态求解与公开基准](GAS-CUV-BENCHMARK.md)登记了独立求解器、公开算例和误差。现有门禁表描述 GAS-M0 案例及现场工程功能。

| 能力 | validation_status | 当前门禁与依据 |
| --- | --- | --- |
| `graph_plan_comparison` | `synthetic_validated` | `ready_synthetic`，沿用 `gas-graph-candidate-0.1.0` 和当前网络、案例、推演配置摘要 |
| `steady_pressure_flow` | `not_business_validated` | `blocked`，缺授权物理拓扑、设备特性、气质、供需边界、独立压力流量对照及签核模型 |
| `supply_adequacy` | `not_business_validated` | `blocked`，还需服务对象和批准的压力、负荷、覆盖口径 |
| `transient_recovery` | `not_business_validated` | `blocked`，还需初始状态、工况时序、独立恢复判据和现场核验 |

`GET /api/v1/gas/engineering/cuv-replay/engineering` 读取当前算例的门禁和校核依据，请求携带网络、案例、推演配置三个摘要。Agent 的 `cuv.engineering.query` 读取状态，`cuv.query` 执行登记的合成图比较。指定其余计算能力时返回缺项和门禁状态。带当前操作主体修订的查询使用既有比较版本检查，版本冲突返回 `409`。审核确认记录合同及输入摘要沿用既有比较接口。

C 类 9 项为后续工程交付的资料及引用。图拓扑的真实阀门及调压设施连接、物理边界时序、测点校准、正式求解器与工况签核仍需另行接收。导入包本身只提供数据源和证据，专业模型需登记已验证版本及适用工况。
