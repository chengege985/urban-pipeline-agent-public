# 智能体应用边界（A_ONLY）

负责人：@catiseyeqaq。本包是后续意图、RAG和编排开发入口。本轮只建立严格合同、Protocol端口和工作流步骤定义，不实现或注册新Agent，不改变冻结 `src/agents`。

- `intent`：领域、问题类型、对象、时间/区域、候选工具和澄清Schema。候选工具是意图假设，不是授权。
- `rag`：文档登记/分块/Embedding/索引端口；只声明生命周期，不扫描材料、不连接向量服务。
- `retrieval`：检索端口，逐请求身份、问题敏感度和语料范围；来源版本和实际文本哈希分开验证。
- `orchestration`：用户输入→意图→权限参数检查→检索/工具→证据→回答→必要时人工确认。步骤说明不是已实现的执行引擎；仍复用冻结LangGraph运行链。
- `tool_adapters`：只能接入共享 `ControlledToolApi`；本轮无具体HTTP适配器，也无Demo回退。
- `contracts`：共享Schema兼容导出，禁止复制业务DTO。
- `evaluation`：独立评测用例入口；当前测试只验证合同与依赖边界，不证明检索质量或自然语言事实蕴含。

仅可依赖本领域、`src.shared_contracts`、标准库及允许的第三方库。不能导入CUV、算法、platform存储/鉴权实现或Agent冻结内核。未来由共享集成层注入受控端口，校验当前服务端身份、数据集、语料和具体操作权限；任何ActorContext字段或confirmation_ref字符串都不能自行升级权限。外发仍须通过现有统一出口和逐请求可信分类。

RAG内容分公开规范、授权内部、合成资料和待确认草案。权限与来源标签不是证据真实性证明，正文哈希也不证明模型结论。内部原件不得跟随源码上传或进入未经批准的外部向量服务。
