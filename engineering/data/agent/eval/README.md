# Agent 评测集（机器初稿）

本目录包含 **100 条路由**、**50 条有答案 RAG + 10 条无答案 RAG** 的机器初稿，以及 12/4 条开发种子。它们用于度量链路回归，**不是人工标注验收集**，不能据此对外宣称已达到 95%/90%。

## 文件

| 文件 | 数量 | 用途 |
| --- | ---: | --- |
| `routing_100.jsonl` | 100 | 四路各 20、组合 10、澄清 5、越权 5；期望任务/意图 |
| `rag_60.jsonl` | 60 | 50 条按 KD01—KD05 分组的可回答查询 + 10 条无答案查询 |
| `routing_seed.jsonl` | 12 | 早期开发种子，保留回归 |
| `rag_seed.jsonl` | 4 | 早期开发种子，保留回归 |
| `build_eval_sets.py` | - | 可重复生成 100/60 初稿；人工复核后再冻结版本 |

## 当前结果（仅证明度量链路）

- 路由：`task_exact=1.0`、`intent_accuracy=1.0`（确定性规则 + 初稿标签）。
- RAG：`recall_at_5=1.0`、无答案 10/10（真实 Qwen3-VL-Embedding 1024 维）。
- 这些数字会随查询改写、语料版本、模型 revision 变化；不得作为最终验收或业务效果。

## 人工复核要求

1. 每条 `annotation` 改为 `human_reviewed`，记录复核人/日期/版本。
2. 四路均衡、组合请求、缺槽位、越权、冲突/失效规则必须覆盖。
3. 50 条有答案必须能在当前语料中定位到原文；10 条无答案必须确认语料确实没有答案。
4. 冻结 `data_version`、`corpus_version`、`embedding_profile`、`model_revision` 后再报告指标。
5. 验收集与开发集分开；不得用本初稿的通过率替代业务验收。
